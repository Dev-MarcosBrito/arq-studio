# ARQ.STUDIO 🏛️

Landing page responsiva e de alta performance desenvolvida para um estúdio de Arquitetura & Interiores de alto padrão. O foco do projeto é unir estética minimalista com excelência técnica (UX/UI).

🔗 **Acesse o projeto online:** [Visualizar Deploy](https://dev-marcosbrito.github.io/arq-studio/)

## 💻 Sobre o Projeto

Este projeto consiste em uma "One Page" focada em conversão e apresentação de portfólio. A interface foi projetada para transmitir sofisticação, utilizando tipografia clássica e um layout "clean", garantindo que as imagens dos projetos sejam o destaque principal.

## ✨ Funcionalidades

- **Design Responsivo:** Layout fluido adaptável para Mobile, Tablet e Desktop.
- **Lazy Loading:** Implementação de carregamento inteligente de imagens (com efeito de *blur*), garantindo pontuação alta no PageSpeed.
- **Animações de Entrada:** Uso de `IntersectionObserver` para revelar elementos suavemente conforme o scroll.
- **Filtro de Portfólio:** Sistema de abas em JavaScript puro para filtrar projetos por categoria (Residencial, Comercial, etc).
- **Menu Mobile:** Navegação otimizada e acessível para dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estrutura acessível e organizada.
- **Tailwind CSS:** Utilizado para estilização rápida e consistente (Design System com cores personalizadas `Brand-Gold` e `Brand-Dark`).
- **JavaScript (Vanilla):** Lógica para o menu, filtros de galeria e otimização de imagens, sem dependência de frameworks pesados.
- **Lucide Icons:** Biblioteca de ícones leves e modernos.
- **Google Fonts:** Combinação das fontes *Playfair Display* (títulos) e *Lato* (corpo).
